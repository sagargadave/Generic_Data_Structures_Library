# Generic Data Structures Library

A generic and reusable C++ library that provides data structure implementations using C++ templates.

## Overview

The Generic Data Structures Library is a C++ project focused on implementing reusable and type-independent data structures.

It uses C++ templates to allow data structures to work with different data types without writing separate implementations for each type.

The project aims to demonstrate generic programming, code reusability, and fundamental data structure concepts in modern C++.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sagargadave/Generic_Data_Structures_Library.git
```

### 2. Navigate to the Project Directory

```bash
cd Generic_Data_Structures_Library
```

### 3. Include the Header File

Include the library header in your C++ program:

```cpp
#include "Datastructures.h"
```

### 4. Compile Your Program

```bash
g++ main.cpp -o main
```

### 5. Run the Program

```bash
./main
```
